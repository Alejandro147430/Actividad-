## Sintesis

El DOM (Document Object Model) o Modelo de Objetos del Documento es una representación estructurada de un documento HTML o XML. Permite visualizar la página como un árbol de nodos, donde cada elemento (como <html>, <head>, <body>, <h1>, etc.) es un nodo dentro de esa estructura. Gracias al DOM, los lenguajes de programación, especialmente JavaScript, pueden acceder, modificar, crear o eliminar elementos de una página web de forma dinámica.

El DOM funciona como una API (interfaz de programación) que sirve de intermediario entre el contenido del documento y el lenguaje de programación. Esto significa que no se trabaja directamente sobre el HTML, sino sobre su representación en memoria. Además, permite agregar eventos a los elementos, lo que hace posible la interactividad (por ejemplo, hacer clic en un botón y que ocurra una acción).

En relación con JavaScript, este utiliza el DOM para interactuar con la página web. Cada elemento del documento puede ser manipulado mediante métodos como getElementById, getElementsByTagName o createElement. El contenido de la página se almacena en el DOM, y cualquier cambio realizado mediante JavaScript se refleja automáticamente en el navegador. El DOM está diseñado para ser independiente del lenguaje, por lo que también puede ser usado con otros lenguajes como Python.

Para acceder al DOM, los navegadores proporcionan un objeto principal llamado document. Cuando se carga una página, el navegador construye el DOM y lo hace accesible al script. A partir de ahí, se pueden realizar acciones como crear nuevos elementos, modificar texto o cambiar la estructura del documento.

Finalmente, existen tipos de datos importantes en el DOM:

•⁠  ⁠document: representa todo el documento HTML.
•⁠  ⁠element: cada etiqueta HTML es un elemento.
•⁠  ⁠nodeList: lista de nodos (como resultados de búsquedas).
•⁠  ⁠attribute: atributos de los elementos (como class o id).
•⁠  ⁠NamedNodeMap: colección de atributos accesibles por nombre o índice.
