## Introducción

HTML, JavaScript y las hojas de estilo en cascada CSS forman la base del desarrollo web moderno.

> HTML estructura el contenido de una página web.

> JavaScript agrega interactividad y dinamismo.

> CSS mejora la apariencia visual y el diseño.

---

## Desarrollo

JavaScript fue creado en 1995 por Brendan Eich para Netscape. Este lenguaje permite validar formularios, crear animaciones y actualizar contenido dinámicamente.

### Imagen relacionada

![Historia de JavaScript](/mnt/data/D8B01B13-09B4-4774-BA1A-C4BC4CF30926.png)

Debido al crecimiento de internet, JavaScript fue estandarizado mediante **ECMAScript**, permitiendo compatibilidad entre navegadores.

Las hojas de estilo en cascada (CSS) ayudan a personalizar colores, tamaños, fuentes y diseños responsivos.

---

## Conclusión

HTML, CSS y JavaScript trabajan juntos para crear páginas web modernas, dinámicas y atractivas.
